# 第一阶段总览

这一阶段用 28 天把三个问题连起来：**声音是什么、它在指板哪里、它在 C 大调里是什么功能**。每天约一小时，固定包含指板、听音、短句或扒歌、和弦推导、复盘和自动补弱。

## 四周路线

| 周 | 目标 | 结束时要做到 |
|---|---|---|
| 第 1 周 | 建立 C、E、G 与局部指板 | 两次试音内找到三个音，完成三音短句 |
| 第 2 周 | 加入 D、A，形成五音范围 | 五音单音题至少八成在两次试音内正确 |
| 第 3 周 | 从单音进入四到六音短句 | 能复现四到五音短句并跟弹基本节奏 |
| 第 4 周 | 减少尝试次数并完成验收 | 独立完成指板、单音、短句和和弦验收 |

## 每天怎么练

课程按顺序推荐，但不硬锁。你可以提前查看任何一天，也可以在同一天同时推进多个能力。真正决定升级的是新题上的表现，不是把同一道题练熟。

遇到真实歌曲时，你只需要自己找到一段速度不快、旋律清楚的录音。网站不提供或保存受版权保护的歌曲，只帮你在旁边记录位置、音名和复盘。
